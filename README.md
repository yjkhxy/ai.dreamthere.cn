## 用一次小任务完成选型

1. 写下一个可验收的目标，例如“把一页会议记录整理成带负责人和日期的待办表”。
2. 在对应分类查看用途；按页面提供的分类、收费状态和排序缩小候选范围。
3. 打开详情，检查价格、平台、语言与资料核验状态。例如 [Flowith 详情](https://ai.dreamthere.cn/site/7929.html) 展示了用途与待补充信息，示例仅用于说明阅读方式。
4. 从卡片或详情点击“加入比较”，在[比较页面](https://ai.dreamthere.cn/site/compare)查看最多三个候选。资料不完整的项目需另查产品网站。
5. 点击“访问官网”前往第三方，用同一份非敏感样例测试；只有输出符合目标、成本可接受，才纳入日常流程。
6. 对暂时用不到的候选点击“收藏”，之后从[我的收藏](https://ai.dreamthere.cn/site/saved)继续查看。

可复制的试用记录：


## 使用前了解这些条件

- **收藏与比较保存在当前浏览器**，不会自动同步到其他设备。清理浏览器数据可能使本地记录丢失。
- **“收费情况未知”不表示免费**。套餐、额度、语言和平台等资料可能待补充，使用前以对应产品网站的当前说明为准。
- **内容更新时间不等于核验时间**。请分别看资料来源、最近核验与各字段状态。
- 网站用于发现与了解工具；工具收录不表示本站已完整测试、官方合作或保证效果。第三方入口可能含推荐参数，请核对最终访问域名。
- 比较前先移除个人与公司敏感数据；是否上传、如何存储及能否用于训练，应查看对应服务的隐私政策。
